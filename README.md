# Household Equity Share

This repository plots the share of household wealth allocated to equities for the United States, Germany, Japan, and China.

Data now comes directly from the OECD Financial Indicators dashboard via the `DF_FIN_DASH_S1M` dataset (measure `LES1M_F51AS`, unit `PT_FAS_S1M`). This indicator reports the share of household financial assets invested in listed and unlisted shares, providing real-world observations instead of placeholder figures.

## Data

- Source: OECD Financial Indicators dashboard, dataset `DF_FIN_DASH_S1M` (data structure `DSD_FIN_DASH`), measure `LES1M_F51AS` (household shares) and unit `PT_FAS_S1M` (percent of financial assets). The SDMX key uses the `FREQ.REF_AREA.MEASURE.UNIT` pattern from the Data Explorer "How to access OECD data via API" instructions; the download script requests the annual series (`A`) for the United States, Germany, Japan, and China.
- Output: `data/household_equity_share.csv` (generated by the download script) with columns:
  - `date`: year-end date (YYYY-12-31)
  - `country`: country name
  - `equity_share`: equity share of household financial assets (percent)

## Usage

1. Install dependencies (for example, in a virtual environment):

   ```bash
   pip install -r requirements.txt
   ```

   If you are behind a proxy, ensure your `http_proxy`/`https_proxy` variables are set. A `403 Forbidden` error while installing
   dependencies indicates the proxy needs to be configured in your environment.

2. Fetch the OECD data:

   ```bash
   python scripts/download_equity_share.py
   ```

   This writes `data/household_equity_share.csv` with the latest values available for each country.

   The download requires outbound HTTPS access to `https://stats.oecd.org`. The script prints the exact URL being fetched and
   will exit with a clear error if the request fails (e.g., proxy blocks or offline environments).

3. Generate the chart:

   ```bash
   python scripts/plot_equity_share.py
   ```

   The chart will be saved to `outputs/equity_share_timeseries.png`.

## Output

Running the script produces a time-series line chart comparing the equity share across the four countries.
